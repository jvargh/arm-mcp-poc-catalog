## Determinism Contract (REQUIRED — every builder must read this)

1. KQL is read from `rules/*.yaml`, never generated by the LLM. String substitution for scope filters only.
2. Every ARG call sequence: `validate_query` → `execute_query`. On `validate_query` failure: mark `INVALID`, do not retry, continue.
3. `run_id` format: `<POC-PREFIX>-{YYYYMMDD}-{scope}-{sha256(rules.yaml)[:8]}`.
4. Sort orders, column headers, section order are pinned in `SKILL.md` and templates.
5. Numeric output is integer unless source data is a percentage (1 decimal).
6. Deploy-capable PoCs: never deploy without explicit user verb (e.g. `apply`, `remediate`) AND a confirm gate; honor global freeze flag from `runbooks/prod.yaml`.
7. PoCs with cancel paths must implement and test (schema/parity test) the cancel path.
8. Tool allowlist in `agents/<slug>.agent.md` MUST match exactly the PoC's "Tools used" line in the source MD — no additions, no omissions.

## Reference Patterns (cite specific files in the reference for builders to mimic)

- **agent.md frontmatter pattern:** `reliability-posture-scorecard/.github/copilot/agents/scorecard.agent.md` lines 1-9. YAML frontmatter with `name`, `description`, `tools` (list with comments).
- **agent.md hard-rules pattern:** Same file, `## Hard rules (do not deviate)` section — numbered list of absolute constraints. `## Tool budget` section — per-verb allowances.
- **SKILL.md numbered procedure pattern:** `reliability-posture-scorecard/.github/copilot/skills/reliability-scorecard/SKILL.md` — YAML frontmatter (`name`, `description`), then `# Procedure` with `## Step N — <title>` sections. Each step is a numbered sub-list of exact operations. Ends with `## Failure handling` and `## Output contract`.
- **rules.yaml schema:**
  - Top-level: `version: 1`, `rules: []`
  - Per rule: `id`, `title`, `severity` (critical/high/medium/low), `weight` (integer), `category`, `remediation_template` (filename or null), `kql` (literal multiline ARG query)
  - KQL MUST return columns `id` and `resourceGroup` at minimum.
- **runbook.yaml schema:**
  ```yaml
  scope: <scope-name>                    # UNIVERSAL — name handle
  subscriptions: ["${subscription_id}"]  # UNIVERSAL — list of sub IDs (placeholder)
  workload_key: resourceGroup            # UNIVERSAL — grouping key (default RG)
  rg_include: ${rg_include}              # UNIVERSAL — allow-list
  rg_exclude: ${rg_exclude}              # UNIVERSAL — deny-list
  # --- PoC-specific keys below this line ---
  # freeze_windows: [...]                # Deploy PoCs only
  # cost_threshold_usd: 500              # Cost PoCs only
  # slo_targets: {...}                   # SLO PoCs only
  ```
- **template placeholder convention:** `{{placeholder}}` only. No Jinja, no Mustache partials, no other syntax.
- **prompt.md pattern:** YAML frontmatter (`mode: agent`, `agent: <name>`), then a one-line instruction, then `Strict requirements:` bulleted list.
